# Kirilica YOLO Reader

Мобильный React/Vite-прототип оверлея для чтения манги с кириллическим текстом.

## Что уже работает

- responsive-интерфейс для Android и desktop;
- встроенная демо-страница манги с кириллическими репликами;
- рамки YOLO с выбором области, фокусом и режимами «Оригинал / Оверлей»;
- редактируемое поле кириллического текста и копирование в буфер обмена;
- встроенный тест на вложениях: 3 скриншота манги с текстовыми областями и 2 UI-скриншота без ложных срабатываний;
- загрузка собственной страницы JPG/PNG/WEBP/SVG;
- встроенные offline-веса: Manga-Bubble-YOLO + PP-OCRv3 detector + Cyrillic PP-OCRv3 recognizer;
- встроенный пайплайн `YOLO → PP-OCR → CTC decode` в браузере через `onnxruntime-web`;
- загрузка собственной модели `.onnx` и запуск внешней YOLO-модели через `onnxruntime-web`;
- порог уверенности, размер текста, zoom-слайдер и pinch-to-zoom на Android;
- PWA manifest для добавления на главный экран;
- Edge TTS для чтения всех распознанных строк голосом `ru-RU-SvetlanaNeural` через локальный Vite proxy;
- запасной голос Android через Web Speech API;
- кнопка Google Lens: текущая страница отправляется в Lens в новой вкладке;
- ленивый каталог папки с рекурсивным поиском `.cbz` / `.cbr` (также `.zip` / `.rar`): другие папки и десятки/сотни архивов сначала показываются как отсортированный список, без распаковки;
- выбранный архив распаковывается только после клика; внутри изображения фильтруются и страницы сортируются естественно;
- непрерывный ридер с автопрокруткой по вертикали и горизонтальной лентой страниц;
- page-aware авточтение: Edge TTS обрабатывает страницы по очереди, а для следующих страниц запускается встроенный OCR;
- студия «Видео из книги»: автоматические роли реплик, два русских голоса Edge TTS, тон/скорость/высота, встроенная атмосферная мелодия, загружаемый трек, звуки переходов и анимация панорамирования;
- браузерная сборка WebM через Canvas + MediaRecorder в щадящем Android-режиме 540×960/24 fps;
- локальный режим для моделей и CBZ: изображение, ONNX-веса, ZIP-распаковка и рендер видео обрабатываются на устройстве; TTS, Google Lens и CBR-распаковка являются отдельными сетевыми/серверными операциями.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте preview на телефоне Android. Для production-сборки:

```bash
npm run build
```

## Встроенные модели

В `public/models/` уже скачаны и подключены:

- `yolo-manga-bubbles.onnx` — Manga-Bubble-YOLO, поиск пузырей/текстовых областей манги;
- `ppocr-cyrillic-det.onnx` — PP-OCRv3 detector, поиск строк;
- `ppocr-cyrillic-rec.onnx` — Cyrillic PP-OCRv3 recognizer;
- `ppocr-cyrillic-dict.txt` — словарь CTC для кириллицы.

Пайплайн находится в `src/lib/mangaOcr.js`: сначала запускается YOLO, затем PP-OCR детекция, затем распознавание кириллицы и CTC-декодирование. Всё выполняется локально через `onnxruntime-web`.

## Edge TTS и Google Lens

- `POST /api/tts` — локальный Vite proxy к Edge TTS, голос по умолчанию `ru-RU-SvetlanaNeural`;
- `POST /api/google-lens` — принимает data URL текущей страницы, загружает его в Google Lens и возвращает URL результата;
- `POST /api/cbr` — серверный fallback на `node-unrar-js`: принимает выбранный CBR как data URL и возвращает изображения страниц;
- UI-кнопки находятся в верхней панели на desktop и в мобильной панели действий.

Edge TTS и Google Lens требуют интернет-соединение: текст отправляется в Edge TTS, изображение — в Google Lens. CBZ распаковывается в браузере, а для CBR выбранный архив временно проходит через Vite middleware, потому что WebAssembly-вариант RAR extractor не во всех Android-сборках стабильно бандлится. Не загружайте конфиденциальные CBR-файлы в публичный preview. ONNX-детекция и OCR остаются локальными.

## Видео из книги

Кнопка «Видео» открывает студию сборки. Для каждой страницы сначала используется уже распознанный текст или запускается локальный OCR, затем реплики распределяются по ролям `Героиня`, `Герой`, `Рассказчик`, `Антагонист`. Профили ролей можно вручную изменить: голос и тон (`спокойный`, `тёплый`, `напряжённый`, `тихий`).

Видео записывается как WebM непосредственно через Canvas/MediaRecorder. Встроенная мелодия создаётся Web Audio без внешнего CDN; при необходимости можно загрузить свой аудиотрек. Также добавляются короткие звуки переходов и эффект панорамы/zoom. Режим 540×960/24 fps выбран как компромисс для Android без лишнего нагрева и задержек. Для очень больших архивов генерация всё равно занимает реальное время: OCR, озвучка и запись выполняются последовательно, но не запускаются при обычном просмотре библиотеки.

## Внешняя ONNX-модель

Кнопка «Добавить внешнюю .onnx» принимает модель детекции с типичным выходом YOLO:

- YOLOv8: `[1, 4 + classes, N]`, например `[1, 84, 8400]`;
- YOLOv5: `[1, N, 5 + classes]`, например `[1, 25200, 85]`.

Универсальный адаптер внешней модели находится в `src/lib/yolo.js`.

## Библиотека папок и ленивое открытие

1. Нажмите «Папка» / «Выбрать папку с мангой» и укажите корневую папку библиотеки.
2. Приложение рекурсивно получает только список файлов через `webkitdirectory`, оставляя архивы нераспакованными.
3. Папки показываются выше архивов и сортируются естественно; внутри папки архивы также идут в естественном порядке (`1`, `2`, `10`).
4. Нажмите на конкретный CBZ/CBR — только он будет прочитан и открыт как книга.

Ограничение браузера: каталог строится из выбранного пользователем дерева через `webkitdirectory`; приложение не получает доступ к произвольной папке устройства без выбора пользователем.

## Проверка на Android

1. Выберите тестовую страницу из блока «Тест из вложений». 
2. Нажмите «Запустить YOLO + OCR» — при первом запуске браузер загрузит встроенные ONNX-веса.
3. Нажмите на рамку или карточку справа — откроется редактор распознанного текста.
4. Переключите «Оригинал / Оверлей» и «Скрыть рамки».
5. На изображении можно использовать pinch-to-zoom; также есть zoom-слайдер.
6. Через меню Chrome выберите «Добавить на главный экран» / «Установить приложение».
